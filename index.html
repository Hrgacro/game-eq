How to use it

Option 1: GameEQ Helper (recommended, Windows)

  1. Download GameEQ Helper and run it. If Windows says “Windows protected your PC”, click More info → Run anyway (the app is open source but not code-signed yet).
  2. The first time, it installs the sound engine for you (Equalizer APO, free and open source). Click through the installer, tick only your headset in the device list (GameEQ tells you which one), and restart if asked.
  3. Allow the one-time permission prompt. The green bars icon appears next to the clock.
  4. Pick your game here and click Apply to my headset. From now on GameEQ switches automatically: start CS2 and your CS2 preset turns on; close it and your normal sound comes back.
  5. Louder mode (tray menu, on by default) keeps your normal volume, so the footsteps really get louder. If the very loudest moments crackle, lower the in-game volume a little, or switch to Safe mode.
  6. New headset, other USB port or a Windows update? GameEQ notices and offers to fix it (tray menu → Check / fix my headset). Undo everything: tray menu → Restore original sound & uninstall.

Option 2: headset app (G HUB, SteelSeries GG, Synapse, NGENUITY…): open its EQ and set each band to the numbers in the table. If it has 5 bands, use 62 Hz / 250 Hz / 1 kHz / 4 kHz / 16 kHz.

Option 3: Equalizer APO by hand: click Download for Equalizer APO, put the file in C:\Program Files\EqualizerAPO\config\ and add the line Include: gameeq.txt to config.txt.

Gunfight tips (when shots hide footsteps)

  • “Gunfight clarity” trims the boom (62–250 Hz) and crack (8 kHz) of gunshots and lifts 2–4 kHz, so shots take up less of the space footsteps need. It helps, but an EQ can't fully separate them, because shots and steps share the same 1–5 kHz range.
  • Compression helps more during fights: it turns loud sounds down and quiet ones up. On Windows: Sound settings → your headset → Enhancements (or Audio enhancements) → Loudness Equalization, if your device offers it. Try it in the Sound test with “Add compression”.
  • Trade-off: with compression, far and near steps sound more alike, so distance is harder to judge. Many players use it only for loud shooters (CoD, Apex, PUBG) and keep it off in CS2. Test both.
  • Keep game volume moderate. When everything is maxed, loud shots “stun” your ears and quiet steps get lost even faster.

Works outside the game (system audio), so it doesn't touch game files and is safe with VAC, Vanguard and FACEIT. It also affects Discord and music on that device.

Headset corrections come from lab measurements (oratory1990, RTINGS, Crinacle via AutoEq) and bring each model closer to a neutral reference before the game EQ is added. Real heads differ: fit, glasses, worn pads and unit-to-unit variation all change the sound a bit. If Full sounds too sharp, use Half. Before using it, set your headset app's own EQ to flat and turn off virtual surround.
